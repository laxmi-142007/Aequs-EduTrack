File Format

Make sure your file uses these column names (CSV or Excel .xlsx).

Required Columns

item_name sku category

Optional / Inventory Columns

unit current_stock low_stock_threshold unit_cost location description status

Important

Item Name: Must contain the name of the inventory item.

SKU: Must be unique for each inventory item.

Category: Must be one of BOOKS, WORKBOOKS, STUDY_KITS, LAPTOPS, SCHOOL_ESSENTIALS or EVENT_MATERIALS.

Current Stock: Opening/current quantity. Defaults to 0 if omitted.

Low Stock Threshold: Quantity at which a low-stock alert is triggered.

Unit Cost: Cost of one inventory unit.

Location: Warehouse, room, rack, shelf, or other storage location.

Status: Must be either ACTIVE or INACTIVE.

Existing inventory items can be updated using their existing SKU.
