File Format

Make sure your file uses these column names.

Required columns

admission_number academic_year class_or_course

Optional columns

marks_obtained total_marks percentage rank promotion_status transfer_school remarks

Important

Admission Number: Must match an existing student.

Academic Year: Example: 2025-2026.

Class: Example: Class 10 or 2nd PUC.

Percentage: Can be supplied directly or calculated from marks.

Rank: Rank is recalculated when records are saved.

Existing records for the same student, year and class are updated.
